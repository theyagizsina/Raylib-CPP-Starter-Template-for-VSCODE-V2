# Aircraft Models

Place your custom aircraft 3D models in this directory.

## Supported Formats:
- `.obj` (Wavefront OBJ)
- `.glb` (Binary glTF)
- `.gltf` (glTF)

## Usage:
1. Copy your aircraft model file to this directory
2. Name it `aircraft.obj`, `aircraft.glb`, or `aircraft.gltf`
3. In the simulator, press **L** key to load the model
4. Press **M** key to toggle between custom model and basic wireframe

## Model Guidelines:
- Models should be reasonably sized (the simulator applies 10x scale)
- Forward direction should align with +X axis
- Up direction should align with +Z axis
- Models with textures should include texture files in the same directory

## Example Files to Try:
- Place your Blender exported .obj or .glb file here
- Make sure texture files are included if your model uses them
